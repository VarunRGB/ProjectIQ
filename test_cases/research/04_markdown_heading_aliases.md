# Campus Navigation Using Graph Algorithms

## Introduction
The project models campus buildings as a weighted graph.

## Review of Literature
Dijkstra's algorithm is discussed in [the classic algorithm reference](https://example.org/dijkstra).
Recent campus routing work is discussed by Chen et al. (2025).

## System Architecture
The graph is updated from building and walkway data.

## Works Cited

[2] L. Chen et al., "Indoor Campus Routing with Dynamic Graph Weights," Smart Cities Review, 2025. https://example.org/campus-routing
