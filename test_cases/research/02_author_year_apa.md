# Project: Detecting Phishing Websites with Machine Learning

## Background
Phishing is a persistent cybersecurity problem.

## Related Work
Smith et al. (2021) studied URL-based phishing detection.
Recent work (Patel and Wong, 2023) explores graph features.
The review links to [the graph learning paper](https://example.org/graph-phishing).

## Proposed Method
The project combines URL and page features.

## References
Smith, J., & Lee, A. (2021). URL features for phishing website detection. Journal of Cybersecurity, 4(2), 20-35. https://example.org/smith-phishing
Patel, R., & Wong, M. (2023). Graph learning for malicious website detection. Security Analytics, 9(1), 1-15. https://doi.org/10.5678/security.2023.22
